# Support

- **Bug reports:** open a GitHub issue and include the Plasticity version, macOS version, Node.js version, the relevant MCP tool name, and a minimal reproduction. Remove local paths, private model data, and credentials first.
- **Feature requests:** open a GitHub issue describing the workflow and the expected result. Include a small example when possible.
- **Security issues:** use the private process in [SECURITY.md](SECURITY.md), not a public issue.
- **Usage questions:** check the [README](README.md), [full tool reference](docs/tool-reference.md), and relevant acceptance guide before opening a question.

This project is maintained on a best-effort basis. No response time or compatibility outside the documented target environment is guaranteed.
